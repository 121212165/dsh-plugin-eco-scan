# DSH 插件生态需求分析 — 开发族研究报告（研究员 A6）

> 分工范围：开发族 = 标签 {12 浏览器, 23 自动化, 24 Shell/执行, 25 Git/提交, 26 编码/代码, 27 文件/目录, 46 诊断/自检}
> 数据源：`eco-data.json`（`window.__DATA__`，快照 2026-11-16，38,549 仓库）；分析基于 rows[] 中 `tags` 含上述 id 的仓库。

---

## 0. 方法与口径

- 行结构 `rows[] = [id, score, stars, weekly, growth, age, seg, act, arch, tags, isMain, isEnriched, x, y]`。
- 本报告所有结论均可由原始 JSON 复算；`weekly=null`（低信号）仓库在下载求和时按 0 计，但单独统计其数量以揭示数据空白。
- 「命中数」= `tags` 数组含该标签的仓库数（可多标签重叠，故各标签之和 > 去重总量）。

## 1. 开发族全景：体量最大、下载最高，但「头部稀疏、尾部低质」

### 1.1 一句话结论

开发族是 14 个族中**下载量最高**的一族：去重后 **9,894 个仓库**，周下载合计 **2,259,867**，占全站周下载 7,837,245 的 **28.8%**，高于交互族（3,559,429，但仓数 18,522 是它的 1.87 倍）之外的所有族；若按"单仓平均下载"计，开发族是头部大族中效率最高的。

1. **编码(3,591) + 文件(2,769) + Git(1,658) 三标签合计 8,018 仓，占开发族 81%** —— 开发族本质上是"代码/文件/Git"三件套驱动。
2. **主榜极度稀疏**：9,894 个开发仓库中只有 **45 个 isMain=1（0.45%）**，9,849 个为低信号；7,876 个（79.6%）`weekly=null`。这说明开发族是一个**长尾、低可见度但需求真实**的市场——大量小工具 plugins 靠搜索/推荐触达，而非靠榜单。
3. **增长分化**：开发族正增长 535 仓、负增长 803 仓，整体中位增长 0；新兴玩法（agent-compare、ops、browser-cdp）暴涨，老工具（context、market）下滑，说明赛道在换挡。

## 2. 七个子赛道逐一分析

### 2.1 编码/代码（tag 26）— 绝对主战场

- 3,591 仓、周下载 789,923、正增长 200 仓、30 天新建 1,208 仓，均为全族第一。
- **Top 仓库**：`tt-a1i/archify`（score 98.8，★96,845，wk 16,124）、`liustack/modlens`（wk 70,692）、`kenryu42/cc-safety-net`（wk 49,920）、`han-1413141/dsh-cost-meter`（wk 38,681）、`xmanrui/dsh-im`（wk 27,898）、`liustack/modsearch`（score 96.1，wk 21,924）。
- **交叉极强**：编码 ∩ 智能体 = 1,049 仓（全站最大跨族交集之一），编码 ∩ 网页 = 665，编码 ∩ 模型接入 = 444，编码 ∩ 技能 = 417。**结论：编码能力是智能体/技能的事实底座，任何"agent 写代码"场景都需要它。**
- **空白信号**：star 合计 428,520 被头部 archify(★96,845)与少数明星拉高，中位数 star 仅 1、p90=10；说明大量仓库是低星工具，**"实用型下载"而非"明星型 star"是这个赛道的真相**（如 `bushizhanghan/dsh-publish-gate` wk=12,011 但 star=1）。

### 2.2 文件/目录（tag 27）— 高频刚需

- 2,769 仓、周下载 562,817、30 天新建 1,169（新建率 42%，全族最高之一）。
- **Top**：`omdsh-dev/dsh-better-sidebar`（wk 96,487，★5,182，score 97.6）、`kenryu42/cc-safety-net`（wk 49,920）、`suifei/dsh-ai-team`（wk 32,083）、`linyanzhi/dsh-mesh`（wk 13,718）、`dshplugin/dsh-plugin-hub`（wk 12,896）。
- 文件标签 ∩ 会话 = 686、∩ 网页 = 617、∩ 工作区 = 565 —— 文件操作嵌入在工作区/会话 UI 中，是"看得见的效率工具"。
- 机会：30 天新建 1,169 仓、但仅 13 个主榜 → 大量新插件在抢占"文件/目录"入口，适合做**聚合型、集成型**（如多根工作区 `cherrchen/dsh-plugin-multi-root-workspace` wk=1,347，score 91.5）。

### 2.3 Git/提交（tag 25）— 下载高、榜单为零的隐形冠军

- 1,658 仓、周下载 586,932（高于文件的 562,817）、star 合计仅 65,001、**主榜 0 个**。
- **Top（按下载）**：`omdsh-dev/dsh-better-sidebar`（wk 96,487）、`lijiaqi-ai-product-manager/dsh-agent-compare`（wk 92,759、grow **951.5%**、age 仅 14 天）、`flymysql/dsh-remote`（wk 79,516、grow 76.8）、`kenryu42/cc-safety-net`（wk 49,920）、`bushizhanghan/dsh-publish-gate`（wk 12,011、grow 71.9、star 1）。
- **代码审查/门禁子赛道**：含 "review" 的开发族仓库 161 个、周下载合计 22,885（如 `michengai/dsh-code-review` wk=5,799、`perrylink/dsh-auto-review` wk=2,071、grow 76.6、`9087/dsh-diff-approval` wk=2,592）；含 "commit" 的开发族仓库 41 个、周下载仅 1,324 —— **审查/门禁有量，提交信息工具类反而弱**。
- 机会：`dsh-agent-compare` 14 天拿下 9.2 万周下载、951.5% 增长，证明"Git + 智能体对比/评审"是强风口。

### 2.4 浏览器（tag 12）— 标杆明确、增速健康

- 1,295 仓、周下载 374,468、star 合计 42,317、正增长 75 仓、新建 456 仓。
- **标杆 `tencent/browserskill`**：score 84.6、★10,434、wk 14,082、tags=[浏览器,命令行,自动化,Shell]，是"浏览器 + 自动化 + Shell"三合一的官方级样板。
- 其他亮点：`drscrewdriver/dsh-browser-cdp`（score 97.4、grow **138.7**、wk 9,607，CDP 协议直连）、`fisfzy/dsh-ego-browser`（score 94.9、wk 10,932）、`bowenliang123/dsh-context`（wk 133,085，浏览器+上下文）、`tingfeng347/dsh-vscode-workbench`（grow 280.8，浏览器里跑 VSCode）。
- 交叉：浏览器 ∩ 网页 514、∩ 会话 234、∩ 桌面 226、∩ 自动化 223、∩ MCP 109。
- 机会：CDP/Playwright 类（`chendefine/dsh-web-fetch-playwright` score 90.8、grow 59.3）与"浏览器书签/知识沉淀"（`browser-bookmark-hub/bookmark-research` grow 272）是新增长点。

### 2.5 自动化（tag 23）— 高增长引擎

- 1,283 仓、周下载 423,430、star 合计 109,366、30 天新建 527（新建率 41%）。
- **标杆 `t-auto/dsh-ops`**：score 98.4、★5,850、wk 73,476、grow 26.9、age 仅 39 天，tags=[自动化,成本,监控,设计] —— 把"运维自动化 + 成本监控"做成一站式，是全族综合分最高的新秀。
- 其他：`xdtrees/dsh-xdpool`（score 97.7、grow 34.6）、`aik358/dsh-auto-memory`（grow 64.8）、`perrylink/dsh-auto-review`（grow 76.6）、`hellohub1212/dsh-windows-mcp`（wk 41,368 但 grow **-94.4**，警示：Windows MCP 红利已退潮）。
- 交叉：自动化 ∩ 智能体 296、∩ 浏览器 223、∩ 模型接入 146。机会在"自动化 + 智能体编排"而非单纯脚本。

### 2.6 Shell/执行（tag 24）— 小众但危险度高

- 仅 696 仓、周下载 94,930，但 star 合计 94,677（接近编码族的 1/4.5）——**少量仓库拿到极高 star**，典型明星即 `tencent/browserskill`（★10,434）。
- **标杆安全插件 `kenryu42/cc-safety-net`** 虽挂在 Git/编码/文件，但含 "safe" 关键字的开发族仓库仅 24 个、周下载合计 50,552，其中 cc-safety-net 独占 49,920（98.8%）——**安全执行/权限防护几乎是"一人供给"的空白市场**。
- 含 "permission" 的开发族仓库 14 个、周下载 2,903（如 `perrylink/dsh-permission-rules` score 95.8、wk 2,221）；含 "sandbox" 的 51 个、周下载仅 1,140。
- 机会：Shell 执行 + 权限规则 + 沙箱，是"高 star、低竞争"的黄金位。

### 2.7 诊断/自检（tag 46）— 全族最弱、明确空白 ⭐

- **312 仓、周下载 35,519、star 合计仅 905（平均每仓 2.9 star）、中位增长 -1.7、正增长仅 14 仓** —— 全族最弱标签，下载量只有编码族的 4.5%。
- weekly>0 的仅 64 仓，且几乎都是小众：`dreamaniax/dsh-syn-config`(wk 2,518)、`perrylink/dsh-lsp-actions`(wk 2,335)、`drscrewdriver/dsh-preset-doctor`(wk 2,099、grow 101.1)、`goodandready/dsh-issue-reporter`(wk 1,997)、`tangyixiao/dsh-provider-doctor`(wk 1,978、grow 146.9)、`dsh-plugin-lab/dsh-plugin-debugging`(wk 1,377)。
- **keyword 证据**：开发族中含 "self-check" 的仓库 **1 个且 wk=0**（`slapaper/dsh-self-checking-profile`）；含 "diagnos" 的 **7 个合计 wk=575**；含 "autofix" 的 **1 个且 wk=0**（`1250589385/dsh-test-autofix`）；含 "rollback" 的 3 个且 wk=0；含 "checkpoint" 的 8 个、wk 合计仅 2,135。
- 交叉稀少：诊断 ∩ 安装 52、∩ 智能体 37、∩ 安全 37、∩ 编码 33、∩ 浏览器仅 5 —— **"浏览器自检""代码提交前自检"几乎无人做**。
- 但已有正向样例验证需求：`perrylink/dsh-checkpoint-rewind`（wk 991）、`1250589385/dsh-rescue-guard`（wk 1,263、grow 264）、`easonmws/dsh-plugin-health`（wk 5,537）、`xiaolu511/dsh-hot-restart`（wk 778）—— 一旦做对，增长很快。
- **结论：诊断/自检是开发族里最确定的空白入口，优先做。**

开发族以 **9,894 仓、周下载 2,259,867（占全站 28.8%）** 成为下载量最高的族，但结构极不均衡：**编码/文件/Git 三件套占 81%**，主榜仅 45 仓（0.45%），7,876 仓无下载数据。**最大的确定性空白是诊断/自检（312 仓、周下载仅 35,519、star 合计 905、中位增长 -1.7）**，以及 Git 提交、Shell 权限护栏这两个"下载高、供给少/单人垄断"的子赛道。建议以「DSH Doctor → CommitGuard → Shell 护栏 → BrowserPilot」四项为第一梯队，用"组合标签 + 交互外壳 + 焦虑型刚需"的标杆打法切入。
