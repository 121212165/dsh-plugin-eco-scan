# 报告一：DSH 插件生态「当前需求」分析与开发推荐

> 任务：基于 `dsh-plugin-eco-scan` / `eco-report-2026-11-06` 数据（快照 2026-11-16，38,549 仓库、50 能力标签），由 **10 个分析 agent** 并行从全局、媒体、认知知识、连接平台、交互、开发、编排、模型数据、设计安全基础设施、蓝海缺口十个视角分析当前需求，产出可推荐开发的插件清单。
> 完成顺序：**本报告（任务一）先完成，再启动任务二（企业未满足需求，5 个 agent）**。
> 数据口径：周下载=存量装机代理；增长率=当期动能；30 天内新建仓=供给拥挤度；矩阵格=需求×能力的供给密度（0/低格=空白）。单快照，`velocity` 数据积累中，增长为样本层信号。

---

## 1. 执行摘要

10 个 agent 的结论高度收敛于一个判断：**当前最强烈的需求不是"再造一个智能体框架"，而是围绕已装机底座（`deepseek-ai/deepseek-harness` 周下载 1,208,788）做"用得上的周边"**——发现检索、会话/工作区体验、成本与路由、安全护栏、远程接入、记忆与知识。这些方向同时具备「高下载 + 高增长/新仓密集 + 热度回升」的需求信号，而高质量供给极薄：

- 搜索/检索在 Top60 仅 **3 席**，却承载 Top30 中 491,365 周下载；
- 工作区×路由/网关矩阵格仅 **28**、工作区×安全仅 **40**、技能/Prompt×成本仅 **43**，不足期望供给的 1/3；
- 安全族 1,848 仓仅 **43 个高分仓（2.3%，全族倒数）**；中文本地化 744 仓、**主榜 0 仓**；数据库 227 仓、`score≥90` 为 **0**；
- 框架/运行时 90.4% 下载来自官方单仓，第三方生态近乎真空；
- 全库仅 **174 仓（0.45%）被富化**，misc-only 3,425 仓（8.9%），触达覆盖率仅 18.16%——"看不见的需求"大于"看得见的供给"。

**结论：优先做"高确定性需求 + 明确结构性空白"的插件，避开通用智能体/侧边栏/生图 wrapper 等红海。**

## 4. 二级推荐（有信号、需验证）

- **多智能体编排控制台 / Agent 对比评测**（A1,A3,A7）：122 个多智能体关键词仓、周下载 34,020、47 个新仓；agent-compare +951.5%；无事实标准，卡位窗口。
- **视觉文档理解 / OCR 复核流水线**（A2,A3）：dsh-pdf-mineru +121.4%、dsh-ocr-review +45.4%；文档视觉是媒体族少有的正增长细分。
- **分镜→成片视频流水线 / 多模态联动创作**（A2）：视频 53.4% 新仓但增长 -3.5、跨媒体组合稀缺；机会在编排/交付层而非再造生成器。
- **EcoEnricher 数据富化器**（A10）：misc-only 3,425、enriched 0.45%、触达 18.16%、velocity 全空——补全数据本身即蓝海（生态级基础设施）。
- **BrowserPilot CDP**（A6,A4）：浏览器×自动化 223 仓、tencent/browserskill ★10,434、browser-cdp +138.7%。
- **通用模型路由/网关 + 自动 Fallback**（A8）：路由仅 1,191 仓、score≥90 仅 9；model-router -70.1% 说明生命周期短。
- **设计 Token / 排版引擎**（A9,A10）：设计列平均 ratio 0.469（全域最薄）；智能体×设计=180(ratio0.314)。

## 6. 方法与局限

- 10 个 agent 各自读取原始数据并用 Node 二次统计，结论可复算；分歧点在字段映射（row[10]=isEnriched、row[11]=coverage），已在综合时以 digest 权威口径校正。
- 单快照、`velocity` overlap=0，增长率为样本层信号而非严格时序；周下载仅覆盖 7,001/38,549 仓，低信号仓需求可能被低估。
- "共识度"为提名该主题的 agent 数，反映交叉验证强度，非投票科学性；最终优先级综合了共识度 + 数据证据强度 + 空白确定性。
